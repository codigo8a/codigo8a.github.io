juandavid.site

A Windows 98–styled desktop simulator that runs entirely in your browser. A personal project by Juan David Ochoa.

What this site is

This is a web recreation of a Windows 98 desktop. It includes a file explorer holding personal notes and tutorials, a notepad, a music player, a browser, a terminal and several other small apps. You can open windows, move them around and use the apps directly in your browser.

No account, registration or login is required to browse or use the site. Everything except the optional Google Drive feature works without signing in to anything.

Google Drive integration (optional)

The “My Drive” app can connect your own Google account so you can create and edit text files in a workspace folder named desktop-web inside your own Google Drive. It requests only the drive.file permission, which grants access exclusively to the files the app itself creates: it cannot read, list or access any other file already in your Drive. Connecting is optional, and the rest of the site works without it.

The access token is kept in browser memory only and is never stored; there is no refresh token, and the session ends when you disconnect or after about an hour. Full details are in the privacy policy linked below.

Qué es este sitio

Es una recreación web de un escritorio de Windows 98. Incluye un explorador de archivos con notas y tutoriales propios, un bloc de notas, un reproductor de música, un navegador, una terminal y varias aplicaciones pequeñas más. No requiere cuenta, registro ni inicio de sesión: todo funciona sin identificarse, salvo la función opcional de Google Drive.

Integración con Google Drive (opcional)

La aplicación “My Drive” puede conectar tu cuenta de Google para crear y editar archivos de texto en una carpeta de trabajo llamada desktop-web dentro de tu propio Google Drive. Sólo pide el permiso drive.file, que da acceso exclusivamente a los archivos que crea la propia aplicación: no puede leer, listar ni acceder a ningún otro archivo de tu Drive. Conectar es opcional y el resto del sitio funciona sin ello.
